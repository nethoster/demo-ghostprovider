# v0.0.48 — GhostProvider without demo-test, honest egress screen, static deploy

## Removed

- **`demo-test` TUI prototype** (`src/tui_v2`, the red monochrome panel variant).
  It had no `__serve-static`/`__egress-shim` workers, so a service deployed
  from it crash-looped with `No such device or address (os error 6)`, and the
  deploy screen pointed at a missing Add Service view.

## Added

- **Static deploy**: a repo with `index.html`, `public/` or `site/` deploys
  as the `static` profile instead of failing with "no supported stack markers found".

## Fixed

- **Self-path**: units write `GHOSTPROVIDER_SELF` -> own binary -> `~/.local/bin`
  -> `PATH` instead of `current_exe()`, which broke deploys started from `cargo run`,
  a copy, or a stale binary.
- **False non-loopback warning**: the shim's and static worker's own listeners
  are no longer reported as a recipe regression.
- **Egress screen** shows all deployed units with their real policy; URL deploys
  read it from the unit file instead of "No services added yet".
- **Preflight** no longer fails on hosts without `systemd-nspawn`; checks
  cgroup v2 and hints `loginctl enable-linger` for post-reboot deploys.

## Release

- Version `0.0.47 -> 0.0.48`, tag `v0.0.48`.
- Rebuild and sign `release/SHA256SUMS` for the new asset:
  `scripts/release-local.sh --sign`.

## Not in this release

- Rust detection (`Cargo.toml`).
- `egress: best-effort` badge for hosts without unprivileged eBPF.
