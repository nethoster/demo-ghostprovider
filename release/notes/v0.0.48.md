# v0.0.48 — GhostProvider без demo-test, честный egress-экран, static-деплой

## Removed

- **`demo-test` TUI prototype** (`src/tui_v2`, красный монохромный вариант панели).
  В нём не было воркеров `__serve-static`/`__egress-shim`, поэтому сервис,
  задеплоенный из него, падал в crash-loop с `No such device or address (os error 6)`,
  а экран деплоя отсылал к несуществующему Add Service.

## Added

- **Static-деплой**: репа с `index.html`, `public/` или `site/` деплоится
  профилем `static` вместо ошибки «no supported stack markers found».

## Fixed

- **Self-path**: юниты пишут `GHOSTPROVIDER_SELF` -> собственный бинарь ->
  `~/.local/bin` -> `PATH` вместо `current_exe()`, который ломал деплой,
  запущенный из `cargo run`, из копии или из устаревшего бинаря.
- **Ложный non-loopback warn**: собственные слушатели шима и static-воркера
  больше не объявляются регрессией рецепта.
- **Egress-экран** показывает все задеплоенные юниты с их реальной политикой;
  деплой по URL читает её из юнит-файла вместо «No services added yet».
- **Preflight** больше не падает на хостах без `systemd-nspawn`; проверяет
  cgroup v2 и подсказывает `loginctl enable-linger` для деплоя после ребута.

## Release

- Версия `0.0.47 -> 0.0.48`, тег `v0.0.48`.
- `release/SHA256SUMS` пересобрать и подписать под новый ассет:
  `scripts/release-local.sh --sign`.

## Not in this release

- Детект Rust (`Cargo.toml`).
- Бейдж `egress: best-effort` для хостов без unprivileged eBPF.
