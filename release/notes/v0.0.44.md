# v0.0.44 — deny-all egress, autopilot deploys, offline builds

The biggest release since v0.0.43: real network isolation for every service,
one-Enter deploys, and builds that finish without internet access.

## Network isolation (egress)

- **deny-all egress in a real network namespace**
  - A service with an empty allowlist runs with `PrivateNetwork=yes` plus a
    socket-activated `__egress-shim`: the unit gets its own netns with
    **loopback only**, and its entire outside world is the localhost tunnel.
    Live-verified: zero routes in the unit's namespace.
  - Allowlist mode keeps `IPAddressDeny=any` + explicit `IPAddressAllow=`
    exceptions; the panel verifies the filter live and says honestly when the
    kernel cannot enforce it (best-effort warning, never silent).
- **egress auto-detect** — the outbound allowlist is derived from the
  project's own config (`auto: true`) instead of a hand-written host list,
  shown for review before deploy.

## Deploy pipeline

- **Offline Python builds** — pip wheels are pre-seeded into a per-project
  wheelhouse with a `.done` marker; installs run `--no-index` from the cache.
- **Manifest detection over a hardcoded catalog** — a pasted GitHub URL is
  detected into a reviewable `service.yaml`; the embedded catalog is gone.
- `source.commit` accepts a **branch name** (tip resolved at each deploy),
  `build.env` is auto-filled from `$env/static/public` imports and `.env`,
  and inlang plugins are auto-pinned from `project.inlang/settings.json`
  (offline paraglide builds no longer compile empty messages).
- Failure reasons survive screen compression; offline-build markers and
  output order are honest; stale unit drop-ins are purged before every write.

## Panel

- **One-Enter autopilot** — on a detected URL: detect → store manifest →
  deploy without leaving the screen; a stale running panel re-execs and
  resumes instead of failing silently.
- **Brand art that fits** — the Pagga art scales 1x–4x to the terminal while
  the menu stays packed, centered and at a fixed style; version shown under
  the panel mark.
- **My Services overview** with deploy marks; **Add Service** gains the
  manifest library, a 9-step in-panel wizard and clickable Create/Import rows.
- **Scan** moves listening ports to a right-hand column and shows Tailscale
  presence; **Logs** walk Deploy/Software/Crash tabs with Left/Right.
- Survives resize storms with adaptive layout, exits cleanly when the tty
  vanishes, and a stall watchdog kills the crossterm tty-wedge spin.

## Security & dependencies

- `rustls` 0.23.46, `rustls-webpki` 0.103.16, `webpki-roots` 1.0.11 — clear
  five fresh RustSec TLS advisories (secret exposure, ECH buffering, brotli
  allocation, ServerHello downgrade, distrusted intermediates).
- `zip` 2 → 9.1.0 — RUSTSEC-2026-0367/0368/0369 (extract SUID/symlink issues).
- `deny.toml` carries exactly one justified ignore: RUSTSEC-2024-0449
  (unmaintained `unsafe-libyaml` via deprecated `serde_yaml`; no libyaml-free
  drop-in exists yet).

## Verified

- `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings`,
  `cargo test` (320 lib + 2 integration, 0 failed), `cargo deny check` — green.
- Single musl build path, byte-identical between `scripts/release-local.sh`
  and `.github/workflows/release.yml` (same pinned-by-digest Arch container,
  pinned rustc 1.98.0, `--locked`).
- Release signature checked in CI against `docs/release.pub`; an unsigned or
  mismatched build is never published.
